# Offline Chatbot

A simple, fully offline Flutter chatbot that **always replies**.

- No internet required
- No cloud, no API keys
- Works on Android
- Clean modern chat UI

## Run

```bash
flutter pub get
flutter run
```

## Important (Java 25 users)

If you see Gradle / Java version errors, point Flutter to JDK 17 or 21:

```bash
flutter config --jdk-dir="C:\Path\To\jdk-17"
flutter clean
flutter run
```

## Features

- Always replies to every message
- Typing indicator
- Light & dark theme
- Clear chat button
- 100% offline reply engine
